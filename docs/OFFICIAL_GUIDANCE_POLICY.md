# Official guidance policy

Do not hard-code campaign recommendations as timeless Meta policy.

When the user asks how a campaign should be structured, the agent must use
current official Meta documentation where available, cite the source URL and
verification date, and separate:

1. `Meta says`: the current documented recommendation or constraint;
2. `Operator recommends`: an account-specific inference;
3. `User decides`: the business or risk choice that remains with the user.

Internet is required to call Meta and to claim guidance is current. When the
internet is unavailable or a cached note has expired, say so. Do not use Reddit
or vendor blogs as the primary authority for technical API behavior.
